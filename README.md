# visionen-templates

Collection of VISIONEN article templates. The PDFs were generated using the files in the latex directory. You can open the example .pdf files to see what an article generated with our templates would look like. 

## How to use the LaTeX templates

1. Set up a LaTeX writing environment (e.g. Overleaf, LaTeX workshop) just be aware the files must be compiled with [LuaTeX](https://www.luatex.org/).
2. The .cls files contain the document class definitions and they should be imported on the top of the .tex file, as can be seen in the examples.
3. Please do not change the .cls file on your machine. If you'd like to submit a change/contribute, send us an email at visionen@vis.ethz.ch.
